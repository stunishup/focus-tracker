# Фокус — трекер годин 🎯

PWA + Android APK з нативними віджетами для трекінгу фокус-годин на інновації.

---

## Як зібрати APK через GitHub (безкоштовно, ~7 хвилин)

### Крок 1 — Створи репозиторій на GitHub
1. Відкрий [github.com](https://github.com) → увійди або зареєструйся
2. Натисни **"New repository"** (зелена кнопка або "+" вгорі)
3. Назва: `focus-tracker`
4. Visibility: **Private** (рекомендую)
5. Натисни **"Create repository"**

### Крок 2 — Завантаж файли
1. На сторінці репозиторію натисни **"uploading an existing file"**
2. Завантаж **всі файли і папки** з цього ZIP, зберігаючи структуру папок
3. Commit: натисни **"Commit changes"**

### Крок 3 — Збірка запускається автоматично
- Перейди у вкладку **Actions** (зверху репозиторію)
- Побачиш workflow "Build APK" — він вже запускається
- Зачекай ~5-7 хвилин поки стане зеленим ✅

### Крок 4 — Скачай APK
1. Натисни на зелений workflow run
2. Внизу сторінки знайди **Artifacts** → `focus-tracker-apk`
3. Скачай ZIP → всередині буде `app-release.apk`

### Крок 5 — Встанови на телефон
1. Перенеси APK на Xiaomi (через кабель, Telegram собі, Google Drive)
2. Відкрий файл на телефоні
3. Xiaomi може запитати дозвіл на встановлення з невідомих джерел → **Дозволити**
4. Встанови

### Крок 6 — Додай віджети
1. Тримай палець на вільному місці головного екрану
2. Вибери **"Віджети"**
3. Знайди **"Фокус"** в списку
4. Перетягни потрібний розмір (малий або великий) на екран

## Структура проєкту

```
lib/main.dart              — весь Flutter код (UI + логіка)
android/
  app/src/main/
    AndroidManifest.xml    — декларація віджетів
    java/.../
      FocusWidgetSmall.java — малий віджет
      FocusWidgetLarge.java — великий віджет
      BootReceiver.java     — відновлення після перезавантаження
    res/
      layout/              — XML розмітка віджетів
      xml/                 — конфігурація провайдерів
      drawable/            — фони та кнопки
.github/workflows/build.yml — GitHub Actions збірка
```

## Функціонал

**Додаток:**
- +1 година (головна кнопка)
- Ввести вручну (виправлення)
- Прогрес-бар поточного тижня
- Понаднормові окремо (не компенсують борг)
- Автозакриття тижня (пн-нд)
- Статистика: використано / втрачено / понаднормово / серія
- Борг у людських одиницях (робочі дні / тижні)
- Історія закритих тижнів

**Малий віджет (4×1):**
- Ризик втратити X годин (червоний)
- При виконанні: "Жодної години не втрачено ✓" (зелений)
- Кнопка +1 прямо на віджеті
- Тап на текст → відкриває додаток

**Великий віджет (4×4):**
- Дати поточного тижня
- Прогрес X/10 год + прогрес-бар
- Ризик/статус поточного тижня
- Три накопичувальні лічильники (використано / втрачено / понаднормово)
- Кнопка +1 та кнопка "відкрити →"
